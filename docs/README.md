## Publication boundary

Safe to publish here:

- current product screenshots made with fabricated data;
- public Help/demo videos;
- architecture and security concepts;
- aggregated test/performance evidence;
- project and contribution summaries.

Kept private during assessment:

- implementation source from the team repository;
- real or reusable credentials and test-account secrets;
- private keys and recovery-key material;
- internal server addresses and privileged operations details;
- raw operational logs containing environment-specific data.

The README and this folder are updated from the private project records only after checking that the material is appropriate for a public portfolio.
